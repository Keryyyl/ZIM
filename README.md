# ZIM

Desktopowy klient mailowy z tagami, regułami i klasyfikacją LLM. Zobacz `CLAUDE.md` po zasady i plan.

## Start

```bash
pnpm install
pnpm dev
```

Wymagania: Node.js 20+, pnpm. Do klasyfikatora (później): Ollama.

Do testów z Gmailem włącz IMAP i użyj hasła aplikacji (weryfikacja dwuetapowa → hasła aplikacji).
